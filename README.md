# 🎲 Ludo Win Zone - Telegram Group AI Bot

এই জিপ ফাইলের প্রজেক্টটি বিশেষভাবে **"Ludo Win Zone"** টেলিগ্রাম টুর্নামেন্ট গ্রুপের জন্য কাস্টমাইজ করা হয়েছে। 

## 🌟 বটের বিশেষ ফিচারসমূহ:
1. **গ্রুপ ফ্রেন্ডলি ও চটপটে:** গ্রুপের মেম্বারদের মেসেজ ট্র্যাক করে এবং নিজে থেকে মাঝেমধ্যে র্যান্ডম মন্তব্য বা আড্ডা জমায়।
2. **লুডু ও ট্রোল মোড:** টুর্নামেন্টে গুটি কাটা, ছয় না ওঠা বা হারজিত নিয়ে মেম্বারদের ফানি পঁচানি ও রোস্ট করবে।
3. **ভালোবাসা ও মিষ্টি মোড:** গ্রুপের কাউকে মিষ্টি কথা বলা বা ভালোবাসার ছলে চ্যাট করার ক্ষমতা।
4. **কনভারসেশনাল মেমোরি:** গ্রুপ চ্যাটের পূর্বের কথা মনে রেখে হিউম্যান-লাইক চ্যাট করতে পারে।

## 🚀 রান করার নিয়ম:
১. জিপ ফাইল এক্সট্রাক্ট করুন।
২. `.env.example` ফাইলের নাম পাল্টে `.env` করুন এবং আপনার Telegram Token ও API Key দিন।
৩. প্যাকেজ ইনস্টল করুন: `pip install -r requirements.txt`
৪. বট রান করুন: `python ludo_bot.py`
